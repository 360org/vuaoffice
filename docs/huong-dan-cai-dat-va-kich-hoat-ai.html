Cài Đặt & Kích Hoạt AI Trên VuaOffice

Thao tác 100% bằng chuột trực quan, dễ dàng kết nối mô hình trí tuệ nhân tạo (Claude, GPT, Gemini) để soạn thảo văn bản, làm bảng tính và tạo slide thông minh.

1 Cài đặt VuaOffice trên Windows (Chỉ 2 phút)

1
Tải file cài đặt Windows
Truy cập vuaoffice.com, nhấp chuột vào nút "Tải về cho Windows" để tải file VuaOffice-Setup.exe về thư mục Downloads.
2
Chạy file cài đặt & Xử lý màn hình SmartScreen
Nhấp đúp chuột vào file VuaOffice-Setup.exe.
💡 Nếu Windows hiện màn hình xanh "Windows protected your PC":
1. Nhấp chuột vào dòng chữ gạch chân: More info (Thông tin khác).
2. Nhấp nút: Run anyway (Vẫn chạy). Ứng dụng sẽ tự động cài đặt và tạo biểu tượng ngoài Desktop.
3
Mở ứng dụng lần đầu
Nhấp đúp chuột vào biểu tượng VuaOffice ngoài màn hình Desktop để mở phần mềm.

1 Cài đặt VuaOffice trên macOS (M1/M2/M3/M4 & Intel)

1
Tải file đĩa ảo .dmg phù hợp với chip máy Mac
Truy cập vuaoffice.com -> Chọn bản Apple Silicon (`arm64.dmg`) nếu dùng Mac M1/M2/M3/M4, hoặc bản Intel (`x64.dmg`) nếu dùng máy đời cũ.
2
Kéo thả cài đặt vào Applications
Nhấp đúp chuột mở file .dmg -> Dùng chuột nhấn giữ biểu tượng VuaOffice kéo thả vào thư mục Applications trong cửa sổ hiện ra.
3
Mở ứng dụng lần đầu & Vượt cảnh báo Gatekeeper
💡 Nếu macOS báo "VuaOffice is an app downloaded from the Internet":
• Cách nhanh: Vào Finder -> Applications -> Nhấp chuột phải vào VuaOffice -> Chọn Open -> Bấm Open xác nhận.
• Cách qua Cài đặt: Vào menu Apple () -> System Settings -> Privacy & Security -> Cuộn xuống bấm Open Anyway.

1 Cài đặt VuaOffice trên Linux (AppImage)

1
Tải file VuaOffice-*.AppImage
Truy cập vuaoffice.com, nhấp nút "Tải về cho Linux" để tải file .AppImage.
2
Cấp quyền thực thi bằng chuột (Properties)
Mở thư mục Downloads trong Files -> Nhấp chuột phải vào file .AppImage -> Chọn Properties (Thuộc tính) -> Thẻ Permissions -> Tích chọn ô: "Allow executing file as program". Sau đó nhấp đúp là mở ngay!
💡 Mẹo: Nếu trên Ubuntu 22.04/24.04 chưa có FUSE, mở Terminal gõ lệnh cài đặt nhanh: sudo apt install libfuse2 -y.

2 Đăng Nhập & Kích Hoạt Tính Năng AI Thông Minh

Quy trình 4 bước chuẩn để kết nối tài khoản và cấp gói trí tuệ nhân tạo (AI Pack) cho VuaOffice:

1
Đăng nhập tài khoản của bạn trên VuaOffice
Nhìn xuống góc dưới cùng bên trái màn hình VuaOffice -> Nhấp vào biểu tượng hình người (Sign in / Đăng nhập).
• Có thể chọn "Đăng nhập bằng Google" (nhanh nhất chỉ 1 click).
• Hoặc nhập Email và Mật khẩu cá nhân/doanh nghiệp đã đăng ký.
2
Kiểm tra trạng thái AI trên menu tài khoản
Khi nhấp vào tên của mình, nếu thấy dòng chữ màu đỏ: ⚠️ Chưa gán AI ... Gán ngay →
Hãy nhấp trực tiếp vào dòng chữ "Gán ngay →" (hoặc mở trình duyệt truy cập: vuahethong.net/my/ai-provider?tab=packs).
3
Kết nối Nhà Cung Cấp & Tạo AI Pack Mới (BƯỚC QUAN TRỌNG NHẤT)
Trên trang web quản lý AI:
  1. Kết nối tài khoản: Bấm "+ Thêm Nhà Cung Cấp" -> Chọn Antigravity CLI (OAuth) -> Đăng nhập tài khoản Google để kích hoạt trạng thái Active.
  2. Tạo AI Pack mới: Nhìn sang mục AI Pack, bấm nút màu xanh: "+ Tạo AI Pack Mới".
  3. Điền thông tin:
    • Tên AI Pack: Nhập tên bất kỳ bạn thích (ví dụ: vanphong, my-ai, work...).
    • Tài khoản kết nối: Tích chọn tài khoản vừa kết nối ở trên.
    • Mô hình sử dụng: Tích chọn các mô hình AI mong muốn (Claude, GPT, Gemini...) hoặc chọn tất cả.
    • Thiết bị áp dụng: Để trống (hệ thống tự động nhận diện thiết bị khi đăng nhập).
  4. Bấm nút "✓ Lưu AI Pack". Gói dịch vụ AI đã được tạo thành công!
4
Tắt VuaOffice và mở lại (BẮT BUỘC KHỞI ĐỘNG LẠI APP)
Sau khi lưu AI Pack thành công trên web:
Bắt buộc khởi động lại ứng dụng:
1. Tắt hẳn VuaOffice: Bấm nút X (Windows/Linux) hoặc nhấn Cmd + Q (macOS).
2. Mở lại VuaOffice: Khởi động lại ứng dụng từ Desktop hoặc Launchpad.
3. Kiểm tra: Nhấp vào tên tài khoản ở góc dưới bên trái, cảnh báo đỏ đã biến mất và thay thế bằng huy hiệu: AI Pack: [Tên_Gói_Của_Bạn] (Đã kích hoạt). Toàn bộ tính năng AI đã sẵn sàng!

3 Trải Nghiệm AI Trợ Lý Trong Công Việc

Ứng dụng Trợ lý AI giúp gì cho bạn? Cách kích hoạt nhanh
📄 VuaOffice Docs (Word) Viết tiếp nội dung, trau chuốt câu từ, sửa lỗi chính tả, tóm tắt hợp đồng dài. Nhấn Ctrl + K (Mac: Cmd + K) hoặc bấm biểu tượng 🤖 Trợ lý AI.
📊 VuaOffice Sheets (Excel) Tự động viết công thức bằng tiếng Việt (SUMIF, VLOOKUP...), đề xuất và vẽ biểu đồ. Mở khung chat AI gõ yêu cầu: "Tính tổng doanh thu nếu đã thanh toán".
📽️ VuaOffice Slides (PowerPoint) Tạo trọn bộ bài thuyết trình tự động từ tiêu đề (dàn ý, nội dung, phối màu). Bấm nút "Tạo Slide bằng AI" trên thanh công cụ.
📑 PDF Studio Chat hỏi đáp hợp đồng, tìm số trang và điều khoản vi phạm trong tài liệu PDF. Kéo thả file PDF vào ứng dụng -> Hỏi đáp trực tiếp với AI bên phải.
