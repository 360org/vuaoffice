## 1. Nguyên nhân Gốc rễ Lỗi Build v1.0.49 và Biện pháp Khắc phục Triệt để

1. **Root Cause Phân tích**:
   - Khi chuẩn hóa định danh kỹ năng sang `vuaoffice`, hằng số runtime `SKILL_NAME` đã được xuất khẩu từ `@genoffice/cli/agent-skills` qua `apps/shell/src/shared/integrations-api.ts`.
   - Do component `IntegrationsPane.tsx` thuộc Renderer client bundle (chạy trong Chromium được Vite đóng gói), việc import giá trị runtime `SKILL_NAME` đã kéo theo module `@genoffice/cli/agent-skills` cùng các thư viện của Node.js (`node:fs`, `node:path`, `node:crypto`).
   - Rollup đã ném lỗi `"join" is not exported by "__vite-browser-external"`, khiến lệnh `electron-vite build` của Shell bị văng trên toàn bộ 5 runner (macOS Intel, macOS Silicon, Linux, Windows x64, Windows ia32).

2. **Biện pháp Khắc phục Triệt để (Structural Fix)**:
   - Tách biệt hoàn toàn tầng Renderer với runtime Node: Khai báo `export const SKILL_NAME = 'vuaoffice'` như một chuỗi hằng số thuần túy trong `apps/shell/src/shared/integrations-api.ts`.
   - Giữ nguyên `import type` đối với các kiểu dữ liệu từ `@genoffice/cli/agent-skills` để trình biên dịch xóa bỏ khi xuất bundle trình duyệt.
   - Thử nghiệm thực tế: Lệnh `electron-vite build` của Shell đã hoàn tất 100% trong 1.72s mà không còn bất kỳ cảnh báo hay lỗi externalize nào.

3. **Tối ưu hóa Phân giải Windows Sidecar**:
   - Hoàn thiện cơ chế fallback tự động cho `xlsx-sidecar.exe` trong `electron-builder.cjs`, tự động quét danh sách candidate paths (cả thư mục target triple và thư mục release tổng).
